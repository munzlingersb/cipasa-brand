3 patterns que aparecem repetidamente nas peças. Cada um documentado para uso direto ou como referência.

## Círculo orgânico

A técnica visual central da marca. Não é decoração — é estrutura. Sempre presente em ads.

**Posições típicas (centros do círculo, num canvas 1080×1080):**
- Top-right: `cx="1080" cy="0"`
- Top-left: `cx="0" cy="0"`
- Bottom-right: `cx="1080" cy="1080"`
- Bottom-left: `cx="0" cy="1080"` (típico em closing cards)
- Left-center: `cx="0" cy="540"`
- Right-center: `cx="1080" cy="540"`

**Raio sugerido:** 480–620px em canvas 1080. Para closing cards (que carregam todo o CTA), use 600–620. Para keyword cards, 480–520.

## Faixa wave lima

Aparece principalmente no rodapé de stories e WhatsApp. Inclinação -12° é fixa. A cor é sempre `{colors.accent}` (`#62BB46`).

## Numeral 35

Pictograma estilizado para situações onde você quer celebrar os 35 anos sem usar o badge completo. Usado em key visuals de outdoor e capa de folder. Para o badge integrado ("CIPASA 35 anos"), use `../logos/cipasa-35anos-badge.svg`.
