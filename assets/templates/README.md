## Convenções dos templates

- **Verde lima dashed** (`#62BB46`): safe zones — não invadir
- **Vermelho dashed** (`#FF6B6B`): danger zones — UI Instagram, sangra de impressão, áreas cortadas
- **Cinza dashed** (`#94A09B`): margens internas opcionais
- **Verde lima solid 1px**: marcação do círculo orgânico nas posições possíveis
- **Boxes preenchidos opaco** (com label): áreas onde elementos devem viver (logo, headline, badges, CTA)

## Como usar

1. Abra o SVG em Figma, Inkscape, ou qualquer editor vector
2. Use as áreas delimitadas como gabarito
3. Substitua placeholders por conteúdo real (foto, texto, badges)
4. Remova as guides antes de exportar a peça final
