# Photography — Banco de Referências Fotográficas

Banco curado de fotos que exemplificam o padrão visual Cipasa. Para regras de captura, edição e mood, ver [`../../PHOTO.md`](../../PHOTO.md).

---

## Como usar

1. Antes de qualquer shoot, baixe as fotos desta pasta e compartilhe com o fotógrafo como **direção visual obrigatória**.
2. Use também o `PHOTO.md` como briefing escrito.
3. Após shoot novo, catalogue aqui com nome descritivo seguindo a convenção: `[tipo]-[contexto]-[mood].jpg`.

## Brief técnico (resumo PHOTO.md)

### Hora preferida
- **Golden hour** (1h antes do pôr-do-sol) para lifestyle, aéreas, key visuals
- **Meio-manhã** (8h–10h) para detalhes arquiteturais

### Composição
- Regra dos terços (sujeito fora do centro)
- Profundidade em 3 planos (foreground / sujeito / background)
- Espaço de respiro pra texto (1 quadrante com baixa info visual)

### Mood / grading
- Levemente cálido (5500–6000K)
- Saturação natural (não Instagram)
- Verde da vegetação pode levar +5–10% saturação seletiva
- Sem HDR, sem flash, sem filtro vintage

### Anti-patterns
- Sorrisos forçados de banco de imagem
- Modelos olhando reto para câmera com cara de "aprovação"
- Pôr-do-sol turbinado
- Crianças "perfeitamente" felizes
- Composição centralizada
