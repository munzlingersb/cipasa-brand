# PHYSICAL — Direção para Materiais Físicos

> Como aplicar a identidade Cipasa em outdoor, folder, merchandise, sinalização, papelaria e veículos. Para criativos digitais, ver [`CREATIVES.md`](CREATIVES.md). Para tokens, [`DESIGN.md`](DESIGN.md).

---

## Princípio

A marca Cipasa em peça física segue as mesmas regras das digitais — **photo-first, círculo orgânico branco, palavra-chave em lima italic** — mas com adaptações de escala, distância de leitura e materialidade.

Diferenças críticas:
- **Outdoor é lido a 50–100m**: tipografia mínima muito maior
- **Folder é lido a 30cm**: pode ter mais detalhe e hierarquia tipográfica
- **Merch é vestido/usado**: identidade discreta, não invasiva
- **Sinalização é navegacional**: clareza > expressão criativa

## Outdoor / Mídia OOH

### Formatos
- **Billboard horizontal** 8:3 (8m×3m / 9m×3m / 32m²) — padrão urbano
- **Outdoor vertical** 1:2 (3m×6m) — fachadas, estádio
- **Mupi / abrigo de ônibus** 1:2 (1.20m×1.76m)
- **Front-light vertical** 2:5 (2m×5m) — empena de prédio
- **Backlight** — mesma proporção mas iluminado por trás

### Composição
Use o template `template-outdoor-8x3.svg` como base.

```
┌──────────────────────────────────────────────────┐
│ ▓▓▓▓ DANGER (estrutura) — não colocar conteúdo ▓▓▓▓ │
│                                                  │
│ foto full-bleed + tint verde 25%        ┌─────┐ │
│                                         │CIPASA│ │
│  Headline — Work Sans 900 italic        │ 35  │ │
│  280-400px (legível a 100m)             │anos │ │
│  ex: "diferença"                        └─────┘ │
│                                                  │
│  Suporte 60-80px (acima do hero)                │
│                                                  │
│ ▓▓▓▓ DANGER ▓▓▓▓                                │
└──────────────────────────────────────────────────┘
                 8000×3000 ou 4800×1800
```

### Regras
- **Uma só ideia** — máximo 7 palavras totais
- **Hierarquia clara** — keyword domina, suporte sussurra
- **Logo + lockup 35 anos** sempre presente, dentro do círculo orgânico
- **Foto em alta resolução** — 300dpi para impressão grande
- **Margens de segurança 120px** em todos os lados (estrutura, fixação, cabos)
- **Cor**: usar perfil CMYK, não RGB. Verde primary `#005A45` em CMYK ≈ `100, 0, 50, 65`

### Tipografia mínima legível
| Distância de leitura | Stroke mínimo letra |
|---|---|
| 30m | 12cm |
| 50m | 20cm |
| 100m | 40cm |

Em outdoor 8m×3m visto a 50m: a palavra-chave `diferença` precisa ter pelo menos 20cm de altura — equivalente a ~1100px no render 4800×1800.

## Folder / Brochure

### Formato padrão
A4 horizontal (297×210mm) dobrado em 3, formando 6 painéis. Use `template-folder-a4.svg`.

### Estrutura

| Painel (aberto) | Conteúdo |
|---|---|
| **3 — Capa** (frente) | Logo Verana + headline emocional + foto hero |
| **2 — Miolo** | Headline + foto principal + grid de amenidades |
| **1 — Verso** | Mapa de localização + dados técnicos + FAQ |

Quando aberto totalmente (297×210mm), o miolo vira **um painel único de 3 colunas**:
- Coluna esquerda — quem somos (Cipasa 35 anos)
- Coluna central — empreendimento (foto + dados-chave)
- Coluna direita — chamada para visita

### Tipografia em folder
- **Capa H1**: Montserrat 800 italic, 48–60pt
- **Miolo H2**: Work Sans 700, 24–28pt
- **Body**: Work Sans 400, 10–11pt
- **Captions/legendas**: Work Sans 400, 8–9pt

### Specs de impressão
- **Papel**: couché fosco 250g (capa) e 170g (miolo, se cadernado)
- **Sangra**: 3mm em todas as bordas
- **Cor**: CMYK, perfil ICC para couché
- **Acabamento**: laminação fosca opcional na capa
- **Dobras**: 2 dobras em 99mm cada (folder em 3)

## Merchandise — Kit 35 anos

Conjunto comemorativo distribuído internamente e em eventos. Mockups das págs 40-43 do manual.

### 1. Camiseta (preta)
- **Material**: algodão 100%, gola redonda, 180g
- **Cor base**: preto (`#000000`)
- **Estampa peito-esquerdo**: logo Cipasa 35 anos versão branca, 10cm largura
- **Estampa costas (opcional)**: tagline "Aqui, fazer bem feito faz diferença." em branco, Work Sans 700, ~12cm largura
- **Tamanho da arte**: peito 10cm / costas 25cm
- **Técnica**: silk em tela ou DTF (alta durabilidade)

### 2. Caneca (branca)
- **Material**: cerâmica esmaltada, 350ml
- **Cor base**: branco (`#FFFFFF`)
- **Estampa frontal**: logo Cipasa 35 anos versão color (verde + lima)
- **Estampa traseira (opcional)**: frase "Aqui, fazer bem feito faz diferença." em verde escuro Work Sans 600, centralizado
- **Técnica**: sublimação ou decalque permanente
- **Dimensão da arte**: 8×6cm

### 3. Caderno A5 (capa dura)
- **Formato**: A5 (148×210mm), capa dura
- **Cor base**: verde escuro Cipasa (`#005A45`)
- **Logo embossed**: lockup completo Cipasa 35 anos em hot-stamping dourado-acobreado ou prensagem cega (textura)
- **Miolo**: 96 páginas pautadas, papel offset 90g
- **Acabamento**: elástico de fechamento, bolso interno

### 4. Ecobag
- **Material**: algodão cru 100%, 220g
- **Dimensão**: 38×42cm + alça
- **Cor base**: cru natural ou verde escuro (`#005A45`)
- **Estampa**: logo Cipasa 35 anos versão branca (se base verde) ou versão color (se base cru), centralizada
- **Tamanho da arte**: 20×15cm

### 5. Caneta
- **Material**: metal escovado, recarga azul
- **Cor**: prata escovado ou preto fosco
- **Marca**: logo "CIPASA" gravado a laser na haste, ~30mm
- **Acabamento**: clip metal, ponta retrátil

### 6. Mousepad
- **Material**: tecido + base antiderrapante de borracha
- **Dimensão**: 22×18cm (compacto) ou 30×25cm (grande)
- **Estampa**: pattern "círculo orgânico" verde muito sutil + logo Cipasa 35 anos no canto
- **Técnica**: sublimação total

### Regras gerais para merch
- Logo nunca menor que 30mm em peça vestível
- Versão branca sobre fundo escuro / versão color sobre fundo claro
- Lima `#62BB46` é acento — nunca cor base de uma peça inteira
- Embalagem: caixa kraft com etiqueta lima (selo de aniversário)

## Sinalização

### Portaria de empreendimento (placa principal)
- **Posição**: ao lado da entrada, perpendicular à via de acesso
- **Material**: chapa metálica 3mm, recorte a laser ou impressão UV
- **Dimensões**: 1.20m × 0.80m (visível de carro a 30km/h)
- **Conteúdo**:
  - Logo Verana grande (versão color)
  - Subtítulo: nome do empreendimento + cidade
  - Tagline: "Bairro planejado em [região]"
  - Lockup CIPASA 35 anos discreto no canto inferior
- **Iluminação**: backlight LED (visibilidade noturna)

### Stand de vendas / Plantão
- **Backdrop principal** (parede de fundo, atrás do atendente):
  - Foto aérea full-wall do empreendimento
  - Sobreposição: forma orgânica branca + headline "Aqui, fazer bem feito faz diferença."
  - Logo Cipasa 35 anos no canto
- **Balcão**:
  - Adesivagem com logo + lima accent na borda
  - Folder à mostra
- **Banner roll-up** (1.80m × 0.80m):
  - Vertical, layout B (impact)
  - Foto + headline + logo + dados de contato
- **Carrinho de bebida / brinde**:
  - Logo monocromático aplicado discretamente

### Way-finding interno (placas internas em empreendimento)
- **Sinalização de áreas comuns** (clube, piscina, academia, redário, etc):
  - Tipografia Work Sans 700, 36–48pt
  - Cor: branco sobre verde escuro `#005A45` ou inverso
  - Pictogramas dos `assets/icons/` (lazer, segurança, natureza)
  - Material: chapa galvanizada com tinta epóxi
- **Numeração de quadras/lotes**:
  - Work Sans 900 italic em verde escuro, sobre fundo branco/creme

## Papelaria Corporativa

### Cartão de visita (90×50mm)
Use `template-cartao-visita.svg`.
- **Material**: papel couché 350g, laminação fosca
- **Frente**:
  - Faixa lima vertical à esquerda (assinatura visual)
  - Logo Cipasa Urbanismo
  - Nome + cargo + dados
- **Verso**:
  - Logo grande centralizado em verde escuro `#005A45`
  - Tagline "Aqui, fazer bem feito faz diferença." em lima

### Papel timbrado A4
Use `template-papel-timbrado.svg`.
- **Material**: papel offset 90g
- **Header**: logo Cipasa Urbanismo (não 35 anos para uso institucional permanente)
- **Footer**: dados de contato + endereço + CNPJ

### Envelope DL (110×220mm)
- **Material**: offset 90g branco
- **Frente**: logo no canto superior-esquerdo, espaço amplo para endereço do destinatário
- **Verso**: faixa lima discreta na aba

### Pasta de apresentação (A4 com bolsos)
- **Capa**: verde escuro `#005A45` com logo embossed
- **Interior**: 2 bolsos para folders e cartão de visita

## Veículos Corporativos

### Carro de serviço / Vendas
- **Lateral**:
  - Logo Cipasa Urbanismo (versão branca) na porta
  - URL `cipasa.com.br` discreto
- **Traseira**:
  - Logo CIPASA 35 anos no canto inferior-direito
- **Cor base**: branco preferencial (não envelopar carro inteiro de verde)
- **Adesivagem**: vinil branco recortado

### Stand móvel / Trailer de vendas
- Wrap completo seguindo identidade
- Foto do empreendimento + headline + dados de contato
- Iluminação interna (banner backlight nas laterais)

## Eventos / Feiras

### Stand 3×3m (módulo padrão de feira imobiliária)
- **Backdrop**: parede inteira com foto aérea + forma orgânica + logo
- **Tótem 2m**: identidade vertical (logo + tagline + QR Code para WhatsApp)
- **Mesa**: branca com toalha lima ou verde escuro, folders à mostra
- **Brinde**: kit 35 anos (caneta + caderno + ecobag) em sacola lima

### Stand 6×6m (feira maior)
- 4 paredes:
  - Backdrop emocional (foto família + tagline)
  - Painel racional (mapa + dados + planta dos lotes)
  - Painel de amenidades (grid 3×3 com fotos das áreas)
  - Painel de credibilidade (35 anos + portfolio + testimonials)
- Espaço de degustação ou café cortesia
- Vídeo institucional em loop

### Lançamento de empreendimento
- Decoração: balões verdes + lima
- Convite impresso: A5 dobrado em 2, capa com headline emocional
- Welcome drink personalizado
- Brinde sofisticado: caderno + caneta em caixa craft

## Cores em peças impressas (CMYK)

Conversão dos hex principais para impressão:

| Token | Hex | CMYK aproximado |
|---|---|---|
| primary | `#005A45` | C100 M0 Y50 K65 |
| primary-deep | `#112A25` | C70 M30 Y50 K85 |
| accent (lima) | `#62BB46` | C60 M0 Y90 K10 |
| badge-35 | `#20592D` | C75 M30 Y90 K35 |
| neutral | `#F8FAF9` | C2 M1 Y2 K0 |

> **Atenção**: imprimir prova de cor em gráfica antes de tiragem grande. Verde lima especialmente difícil — pode tender ao amarelo se separação CMYK estiver errada.

## Ordem de prioridade em compra de materiais

Se precisar priorizar (orçamento limitado), comprar nesta ordem:

1. **Cartão de visita** + **papel timbrado** — uso diário
2. **Folder de empreendimento** — peça mais usada por venda
3. **Banner roll-up** — para stand e eventos
4. **Camiseta + caderno + caneca** — kit interno (cultura)
5. **Outdoor** — campanhas pontuais
6. **Sinalização de empreendimento** — quando há novo lançamento
7. **Wrap de veículo** — apenas se há frota corporativa
